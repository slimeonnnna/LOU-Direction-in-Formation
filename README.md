# LOU / Direction in Formation

Lou 的个人作品集网站。

这不是一份传统的在线简历，而是一段关于进入 SEO、主动发现问题、承担完整结果，并持续扩展能力边界的成长叙事。

## Live site

[lou-direction-in-formation.cautiousslug.chatgpt.site](https://lou-direction-in-formation.cautiousslug.chatgpt.site)

## Design direction

- 编辑式中文排版与非对称网格
- 暖白纸张、炭黑文字与单一朱红强调色
- 一条随滚动贯穿六个章节的连续路径线
- 以经历和真实工作呈现能力，避免履历面板、技能标签墙和夸张指标
- 响应式移动布局、键盘导航与 `prefers-reduced-motion` 支持

## Development

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Production validation:

```bash
npm run build
npm run lint
```

## Stack

- React 19
- Next.js / Vinext
- TypeScript
- CSS and inline SVG interaction
- Cloudflare-compatible deployment output
